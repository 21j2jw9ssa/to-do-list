  • What an item looks like

    Each item looks like the following:

  • drag_indicator
    example item as a demo
    edit_square
    delete
    • The drag_indicator icon
    An icon to drag an entire item and drop it at a specific position.
    Once dropped, it has the list updated.
    Item content
    The essential part of an item to clarify what to be done.
    It must contain at least one non-space characters,
    e.g. numbers (0~9), letters (A~Z, a~z) and symbols.
    The checkbox
    As a checkbox which is used to toggle the status of the item between the done state and the not-done state.
    When clicked, it switches between and ,
    then has the list updated.
    A checkbox's binary status:
    : item is not yet done; its content is purely black.
    : item has already been done; its content is gray and crossed out.
    The edit_square icon
    Allows a user to edit a specific item.
    The item after being editted must be neither empty nor with mere spaces.
    Once done, it has the list updated.
    The delete icon
    Allows a user to delete a specific item.
    This action cannot be undone once it is clicked, however.
    Once done, it has the list updated.

  • Add item

    Adds an item to the list buffer at a time.
    It can be done by pressing Enter, too.

    An item to be added must not be empty.
    An item that is made up of space(s) only is not acceptable, either.

    Take the following table as an example:

    example OK?
    Good morning OK
    biscuits OK
    But I'm OK! OK
    '' (empty) NOT OK
    ' ' (a space) NOT OK
    '    ' (spaces only) NOT OK

    Caution!

    It's highly not suggested to enter something associated with personal identity or info.

  • Sort items

    Sorts all items in the list by a specific property such as contents and checkbox status.

    By default, the list starts empty.
    That is, the dropdown list is not for use at this state.
    To enable the dropdown list, there should be at least one item in the list.
    To make it, import a to-do list or add an item to the list.

    There are four ways to sort items:

    Smallest to largest

    Arranges all items from smallest to largest,
    i.e. A to Z, a to z, 0 to 9, etc.

    After sorting
    the greater an item is, the closer it is to the bottom of the list buffer;
    the smaller an item is, the closer it is to the top of the list buffer.

  • Delete list

    Clears all items in the list buffer.
    The list, if saved in the web browser, remains unchanged.

  • Export list

    Exports all items in the buffer as a list in a text file.
    All items in this list can be seen in the exported file.

    The following explains how to download a list consisting all items in the list buffer, depending on the web browser a user is using.

    Windows
    macOS
    iOS
    Android
    Linux

    Select a text file, i.e. a file that ends with .txt from the dropdown. Avoid selecting from “All files”

    All files may appear. Ensure you pick a file ending in .txt.

    Tap “Browse” and select a .txt file. Long-press to view file info if extensions are hidden.

    Use the system file browser to locate a .txt. File filters may not be strict.

    All files appear. Pick a file that ends with .txt.

    Once exported, the file looks like the following:

    item1, checked1
    item2, checked2
    item3, checked3
    ...
    itemN, checkedN

    where for each item,
    itemN is the contents,
    and checkedN is the checkbox status (true or false only).

  • Import list

    Imports the list from a file.
    A file to import must be a text file i.e. ends with .txt.
    Any attempt to load a file that doesn't end with .txt results in an error.

    Generally, a file picker jumps out and asks you to pick a file.
    If possible, select the filter with TXT files so that only text files can be selected.
    If not, select a file that ends with .txt.

    Make sure the file to import follows the following pattern:

    item1, checked1
    item2, checked2
    item3, checked3
    ...
    itemN, checkedN

    where for each specific item,
    itemN is the contents,
    and checkedN is the checkbox status (true or false only).

    Any flaws found in the file results in an error,
    pointing out the line where the first error is found.

    Look at the following cases:

    case 1
    case 2
    case 3

    Case: checkbox status not valid

    If an item's checkbox status is neither true nor false ,
    there is no way to tell whether it's done or not.

    An item with checkbox status neither true nor false results in an error.

    For example:

    Line
    1 | John, false
    2 | Jessica, true
    3 | Albert, false, folk
    4 | Simon, trust
    5 | Billy, true
    6 | Paul, fault

    The first error will be found on line 3
    because while the item's content is present, i.e. 'Albert, false',
    its checkbox status is 'folk', which is neither true nor false.

    Case: item's content is empty (no sided spaces)

    An item must have a content: it's essential part of the list. Not giving content of an item results in an error.

    For example:

    Line
    1 | sweets, true
    2 | crisps, true
    3 | maize, false
    4 | Simon, false
    5 | capsicum, true
    6 | salmon, false
    7 |   ,false
    8 | ice lolly, false

    The first error will be found on line 7
    because after getting rid of spaces from both sides of the item's contents, the item is simply empty.

    Case: missing checkbox status

    An item must have a checkbox status in order to tell if it's done or not.

    Not giving a checkbox status of a item results in an error.

    For example:

    Line
    1 | screw, false
    2 | hammer, folk,
    3 | turpet, true
    4 | tape, trust
    5 | helmet,
    6 | drill, fault
    7 | tractor, fault
    8 | vibrator, fault
    9 | steel, fault

    The first error will be found on line 2
    because while the item's content is present, i.e. 'Albert, folk',
    its checkbox status is not given.

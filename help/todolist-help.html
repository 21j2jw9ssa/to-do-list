How to use To-do List

order by:

  • Add an item

    • Add an item to the list at a time.
    For desktop and laptop users,
    it can be done by pressing Enter, too.

    An item to be added should NOT be empty.

    For example:

    • 'Good morning' - OK
    • 'biscuts' - OK
    • 'But I'm OK!' - OK
    • ' ' - OK
    • '' - NOT OK

  • Save

    • Save the list in the web browser.
    If there is already a list saved in the web browser, users may either overwrite it with a new list.

    OK to overwrite the old list with a new one
    Cancel to do nothing

  • Sort items

    • Sort all items in the list.
    To do so, there should be at least one item in the list buffer.

    There are four ways to sort items:

    • smallest to largest

      Arrange all items from smallest to largest, i.e. A-Z, a-z, 0-9
      After sorting: the greater an item is, the closer it is to the bottom of the list; the less an item is, the closer it is to the top of the list.

    • largest to smallest

      Arrange all items from largest to smallest, i.e. Z-A, z-a, 9-0
      After sorting: the greater an item is, the closer it is to the top of the list; the less an item is, the closer it is to the bottom of the list.

    • latest done to earliest done

      Arrange all items by checkbox status from latest done to earliest done.
      After sorting:

    • earliest done to latest done

      Arrange all items by checkbox status from latest done to earliest done.

  • Load

    • Load the list saved in the web browser.
    This only works when there is a list saved in the web browser.

  • Clear list

    • Clear all items of the list;
    the list (if saved) in the web browser remains unchanged.
    This only works when there is at least one item in the list.

  • Delete

    • Delete the list stored in the web browser;
    the list buffer remains unchanged.
    This only works when there is a list saved in the web browser.

  • Export

    • Export the list as a file (text files only).
    All items in this list can be seen in the exported file.

    Once exported, the file looks like the following:

    item_content1, checked1
    item_content2, checked2
    item_content3, checked3
    ...
    item_content_N, checked_N

    where for each specific item,
    item_contentN is the contents,
    and checkedN is the checked status (true or false only).

  • Import

    • Import the list from a file (text files only).

    Make sure the file to import follows the following pattern:

    item_content1, checked1
    item_content2, checked2
    item_content3, checked3
    ...
    item_content_N, checked_N

    where for each specific item,
    item_contenN is the contents,
    and checkedN is the checked status (true or false only).

    Any flaws found in the file results in an error,
    pointing out the line where the first error is found.

    When attempting to import the following file, for example:
    Line
    1 | John, false
    2 | Jessica, true
    3 | Albert, false, folk
    4 | Simon, trust
    5 | Billy, true
    6 | Paul, fault

    The first error will be found on line 3,
    pointing out that while
    the contents is present, i.e. 'Albert, false',
    its checkbox status is neither 'true' nor 'false'.
